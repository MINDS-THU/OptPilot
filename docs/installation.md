# Installation

Install Python 3.10 or later and uv, then clone the public Core:

```sh
git clone https://github.com/MINDS-THU/OptPilot.git
cd OptPilot
uv sync
uv run optpilot --help
```

OptPilot Desktop uses the same project manifest and experiment ledger as Core. Its source is maintained privately. Installers for macOS, Windows and Linux are planned for the public GitHub Releases page after acceptance. [OptPilot Releases](https://github.com/MINDS-THU/OptPilot/releases)
