# OR solution records

Open `catalog/or_solving`. The `solve` Study invokes the real COOPA generator using the public problem in Task observations. Configure COOPA_HOME and its provider dependencies. The Grader checks a well-formed report and finite numeric answer; it does not prove optimality.

For simulation policies improved through measurement, use [Generate and improve](generate-and-optimize.md). Choose the route based on whether you can specify a mathematical model or need an executable grader.
