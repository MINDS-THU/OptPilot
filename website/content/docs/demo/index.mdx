OptPilot Desktop lets you work on an experiment with its files, evaluations and conversations in one place. Open a project folder to inspect its saved candidates and results. The public Core CLI can read and run that same project.

## From a result to a revision

1. Open the document-search example. Choose its five-question suite and both ranking programs, then review the selection and start the evaluation.
2. Open the comparison in the project graph. Select a trial to see what the user asked, which article the grader expected and where the candidate ranked it.
3. Attach that trial to a conversation. A coding assistant can use the ranked list to investigate the program. Save the revision as a new candidate version and compare it on the original questions.

[Follow the Desktop tutorial](https://minds-thu.github.io/OptPilot/reference/ui/)

## Install Desktop

When a build is published for your platform, its installer and installation notes will appear on the [GitHub Releases page](https://github.com/MINDS-THU/OptPilot/releases). Desktop is distributed separately with private source. You can also run the [same comparison with the open-source Core CLI](https://minds-thu.github.io/OptPilot/reference/getting-started/).
