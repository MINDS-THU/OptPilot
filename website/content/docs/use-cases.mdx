						)}

					</div>

# Research Packages

The repository contains three paper companion projects and one deliberately small tutorial project. They are executable examples: each project declares experiment artifacts and Studies that exercise the same public Core contracts.

<UseCasesGrid />

The companion packages cover simulation generation, parameter tuning, executable policy design from event traces, and natural-language operations-research solving. The [tutorial package](https://minds-thu.github.io/OptPilot/reference/tutorial-package/) is the shortest path for learning how to author your own integration.

For exact commands, prerequisites, limitations, and paper links, use the [DEVS-Gen](https://minds-thu.github.io/OptPilot/reference/devs-gallery/), [heuristic-design](https://minds-thu.github.io/OptPilot/reference/llm-policy-search/), and [COOPA](https://minds-thu.github.io/OptPilot/reference/or-solving/) guides.
