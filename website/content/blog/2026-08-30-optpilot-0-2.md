When you revise a program, its earlier scores are still relevant. You need to know which cases it saw, how it was graded and which version produced each result. OptPilot Core 0.2.0 records those details for experiments run from the CLI or Desktop.

{/* truncate */}

## Before a run

A review resolves the selected candidates, cases and grading code to saved project versions. It also captures the metric, repetitions and run settings. You can launch that reviewed study again after the working files change. External dependencies such as a hosted model or an instrument still have their own versioning and availability.

## After a run

Each trial identifies the candidate and case, the attempts made, any failures, and the measurements and evidence the grader returned. A generator can receive the task’s approved feedback metrics and propose the next batch of candidates. Its proposals and their evaluations become part of the project record.
