OptPilot Desktop 把实验文件、评测结果和会话放在同一个工作区。打开项目文件夹，就能查看保存过的方案和评测。公开的 Core 命令行也可以读取并运行同一项目。

## 从一次评测走到下一次修改

1. 打开文档检索示例，选中包含五个问题的实例集和两种排序程序。检查评测设置后启动运行。
2. 在项目关系图中打开评分比较。选中一个试验，就可以看到用户问了什么、评分程序期望找到哪篇文章，以及该方案把它排在第几位。
3. 把试验证据加入会话。编程助手可以根据这份排序结果检查代码。把修改保存为新版本，再用原来那组问题比较效果。

[阅读 Desktop 操作教程（英文）](https://minds-thu.github.io/OptPilot/reference/ui/)

## 安装 Desktop

对应平台的安装包发布后，可在 [GitHub Releases](https://github.com/MINDS-THU/OptPilot/releases) 下载并查看安装说明。Desktop 单独分发，源码保存在私有仓库。你也可以使用[开源 Core 命令行运行同一个示例](https://minds-thu.github.io/OptPilot/reference/getting-started/)。
