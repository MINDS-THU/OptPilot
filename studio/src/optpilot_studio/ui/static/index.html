Local environment variables

Store local values that configs may request by name. A new Run binds the current saved revision; changing it later affects new Runs, not that Run.

Add each variable here, then save settings to persist the changes.

Values are write-only in the browser, but OptPilot stores them as plaintext in its local settings file. Run records contain only the variable name and an opaque local revision—not the value. This is not a secret vault. Use remove to clear a stored value.
